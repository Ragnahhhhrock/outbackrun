OUTBACK RUN

OFFICIAL STYLE GUIDE — VERSION 1.0

Brand Identity

Outback Run is a retro-arcade racing game set in the Australian Outback. Every visual asset — from title cards to in-game sprites — must conform to this style guide to ensure visual consistency and brand recognition.

Core Concept: 1980s arcade aesthetic meets Australian outback iconography. Think OutRun meets the Nullarbor Plain. Bold colors, thick outlines, sunset gradients, and unmistakably Aussie motifs.

The Official Gradient

The signature horizontal gradient is the most recognizable visual element of the brand. It must be applied consistently across all title text and primary branding.

Sky Blue #01B5EASunset Yellow #FBDA03Desert Red #F70409
Gradient Rules: Direction is always top-to-bottom horizontal bands (not vertical, not diagonal). Approximate distribution: Blue 40% / Yellow 30% / Red 30%. The transition between bands should be smooth but distinct.

Typography

The Outback Run logo uses a bold, retro cursive script. While an exact font match may not always be available, all in-game text must emulate these characteristics.

Primary Type Style

Form: Bold, flowing cursive / script with rounded terminals

Weight: Heavy / Black (minimum 700 weight)

Slant: Slight forward italic (10–15 degrees)

Stroke: Calligraphic variation — thick downstrokes, thinner upstrokes

CSS Fallback Stack: 'Brush Script MT', 'Segoe Script', 'Comic Sans MS', cursive

Visual Treatment

1. Drop Shadow

Every major text element and prominent UI component must include a hard-edged drop shadow. No Gaussian blur — the shadow must have crisp edges to maintain the retro arcade feel.

Color: #150C28 (Midnight Purple) or #070415 (Deep Space) for darker scenes

Offset: +4px horizontal, +6px vertical (down-right)

Blur: 0px (hard edge only)

2. Outline Stroke

A thick dark outline separates text and key shapes from backgrounds. This is essential for readability against busy outback scenery.

Color: #150C28

Weight: 3–4px for titles, 2px for UI elements

Position: Outside (center or inside only if outside is impossible)

3. Gradient Fill

Primary branding text always uses the horizontal blue-yellow-red gradient. Secondary elements may use solid colors from the palette.

Imagery & Theme

Approved Motifs

  • Red desert landscapes, sand dunes, salt flats
  • Eucalyptus trees, spinifex grass, red dirt
  • Road trains, utes, muscle cars, vintage Australian vehicles
  • Kangaroos, emus, wombats, dingoes, cockatoos
  • Endless straight highways, horizon lines, big skies
  • Sunsets with orange/red/purple gradients
  • Retro 80s chrome, neon accents, grid patterns
  • Roadside signs: fuel stops, roadhouses, kilometer markers

Prohibited Motifs

  • City skylines, skyscrapers, urban environments
  • Snow, ice, forests, beaches (unless explicitly Nullarbor coastal)
  • Modern cars (post-2000 design language)
  • Realistic photorealistic textures — keep it stylized/illustrated
  • Non-Australian animals or landmarks
  • Vertical or portrait-oriented compositions for gameplay screens

Do's and Don'ts

DO

  • Use exact hex colors from this guide
  • Apply the horizontal blue-yellow-red gradient to titles
  • Include the midnight purple outline on all text
  • Use bold, rounded, cursive letterforms
  • Include Australian outback motifs (kangaroos, road signs, desert)
  • Design for landscape orientation (16:9 or wider)
  • Use retro 80s arcade aesthetic throughout
  • Add hard-edged drop shadows to prominent elements
  • Use diamond warning signs with yellow/black
  • Keep sprites and UI readable at small sizes

DON'T

  • Use vertical, diagonal, or radial gradients for branding text
  • Use thin, serif, or geometric sans-serif fonts for titles
  • Omit the dark outline or shadow on text
  • Use pastel, muted, or desaturated colors
  • Use modern flat design (no shadows, no depth)
  • Use portrait orientation for gameplay screens
  • Create imagery that doesn't fit the Australian outback theme
  • Use photorealistic textures or 3D renders
  • Use circular or triangular warning signs
  • Change the color of the kangaroo sign motif

Application Examples

Game Title Screen

Full logo with gradient fill, purple outline, hard shadow, and kangaroo road sign. Background: animated sunset over desert highway.

UI Buttons

Gradient or yellow text with purple outline on dark semi-transparent panel (#150C28 at 80% opacity). Hover state: brighten gradient 15%.

Score / HUD Display

Large yellow (#F9DC03) numerals with purple outline and shadow. Position: top-center or top-right, always readable against sky.

In-Game Warning Signs

Diamond yellow signs with black silhouettes. Appear as roadside objects or overlay warnings. Scale: 48×48px minimum.

Vehicle Sprites

Retro-styled cars with bold outlines, chrome highlights, and gradient accents. Side-view or rear-view for racing perspective.

Background Layers

Parallax desert scenery: red dirt foreground, spinifex midground, purple-orange sunset sky. Keep silhouettes simple and bold.

Loading Screens

Dark background (#070415) with centered logo, animated gradient shimmer, and loading bar in blue-yellow-red.

Game Over Screen

Large red (#F70409) text with heavy shadow. Subtext in yellow. Background: darkened game scene with vignette.

Mobile & Browser Specifications

Outback Run is designed primarily for mobile players in landscape orientation.

PropertySpecification
Primary OrientationLandscape (force landscape in browser)
Aspect Ratio16:9 minimum, 21:9 ultrawide supported
Minimum Resolution640×360 (mobile) / 1280×720 (desktop)
Touch TargetsMinimum 44×44px for all interactive elements
Text LegibilityMinimum 16px body text, 24px headers at 360px width
Safe AreaKeep critical UI within central 80% of screen
Landscape Lock: The game must force landscape orientation in mobile browsers. If the device is held in portrait, display a rotate-device message using the style guide colors and typography.
